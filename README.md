# Öğrenci Başarısını Etkileyen Faktörlerin Analizi

## Proje Hakkında
Bu proje, öğrencilerin çalışma süresi, devamsızlık durumu ve önceki dönem notları ile matematik dersi dönem sonu başarıları arasındaki ilişkileri incelemek amacıyla hazırlanmıştır.

## Araştırmanın Amacı
Öğrenci başarısıyla ilişkili olabilecek faktörleri veri analizi yoluyla incelemek ve sonuçları tablo ve grafiklerle sunmak.

## Araştırma Sorusu
Çalışma süresi, devamsızlık sayısı ve önceki dönem notları ile matematik dönem sonu notu arasında nasıl bir ilişki vardır?

## Veri Seti
UCI Machine Learning Repository üzerinde yayımlanan Student Performance veri seti kullanılacaktır.

Veri kaynağı: https://archive.ics.uci.edu/dataset/320/student+performance

- Nicel araştırma yaklaşımı
- İkincil veri analizi
- Betimsel istatistikler
- Tablo ve grafiklerle karşılaştırma
